# Google Ads — Local Read-Only Scripts

Standalone Node/TypeScript scripts that connect to the Google Ads API and run
**read-only** queries against the SixSigma account. Nothing here ships to
Vercel — these run only on your machine.

## One-time setup

Gather the following and paste into `.env.local` (already in `.gitignore`):

| Variable                        | Where to get it                                                                                          |
| ------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `GOOGLE_ADS_DEVELOPER_TOKEN`    | [API Center](https://ads.google.com/aw/apicenter) inside your Manager (MCC) account → Apply for access. |
| `GOOGLE_ADS_CLIENT_ID`          | [Cloud Console](https://console.cloud.google.com) → enable Google Ads API → Credentials → OAuth 2.0 Client (Desktop app). |
| `GOOGLE_ADS_CLIENT_SECRET`      | Same place as Client ID.                                                                                  |
| `GOOGLE_ADS_CUSTOMER_ID`        | Top-right of [ads.google.com](https://ads.google.com), 10 digits, **dashes stripped** (e.g. `1234567890`). |
| `GOOGLE_ADS_LOGIN_CUSTOMER_ID`  | (Optional) The MCC's 10-digit ID, dashes stripped. Required if your customer is under a manager.         |
| `GOOGLE_ADS_REFRESH_TOKEN`      | Generated by `get-refresh-token.ts` (step 2 below).                                                     |

### Step 1 — Add the first 4–5 vars to `.env.local`

Copy the block from `.env.example` and fill in everything except
`GOOGLE_ADS_REFRESH_TOKEN`.

### Step 2 — Generate the refresh token

```bash
npx tsx scripts/google-ads/get-refresh-token.ts
```

A browser window opens. Sign in with the Google account that has access to
the SixSigma Ads account. After consent, a refresh token is printed in your
terminal — paste it into `.env.local` as `GOOGLE_ADS_REFRESH_TOKEN`.

> If no refresh token comes back, revoke previous access at
> [myaccount.google.com/permissions](https://myaccount.google.com/permissions)
> and re-run.

## Running the scripts

```bash
# Smoke test — confirms credentials are valid
npx tsx scripts/google-ads/test-connection.ts

# All campaigns with status, channel, daily budget
npx tsx scripts/google-ads/list-campaigns.ts

# Last 30 days: impressions, clicks, cost, conversions per campaign
npx tsx scripts/google-ads/campaign-performance.ts
```

## Notes

- All scripts use **GAQL** (Google Ads Query Language). Schema reference:
  https://developers.google.com/google-ads/api/fields/v17/overview
- All scripts are read-only — there are no `mutate` calls.
- If you see `DEVELOPER_TOKEN_NOT_APPROVED`, your token is still in test mode.
  You can use it against a test account or wait for Basic Access approval.
- If you see `USER_PERMISSION_DENIED`, the Google account you authorised
  doesn't have access to the customer ID. Either grant access in Google Ads
  or re-run `get-refresh-token.ts` with a different account.
